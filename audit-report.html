HealthLens Audit Report

Accessibility and content audit documentation for HealthLens V1.2. This report records manual checks, content boundary reviews and known limitations. The project is WCAG-informed, but not formally certified.

Markdown versions: accessibility audit · content audit · manual test plan

Audit overview

HealthLens V1.2 adds structured audit documentation to support portfolio review, job applications and interview discussion. Automated scores (Lighthouse, axe) and full manual keyboard testing are recorded as placeholders until completed.

Accessibility checklist

  • Skip link to main content
  • One h1 per page; logical heading hierarchy
  • Visible form labels on search and filters
  • Keyboard-accessible navigation, buttons and links
  • Visible focus states
  • Descriptive link text on cards and external links
  • aria-live search status region
  • Dark mode readable contrast (manual check pending)
  • Print CSS for key content (manual check pending)

Content checklist

  • Page purpose and audience stated on topic pages
  • Source labels visible on resource and guide cards
  • “Last checked” used consistently — not “last updated” for external sources
  • Limitation notes on high-risk topics
  • No medical, legal, financial or immigration advice claims
  • Commercial platforms labelled separately from official/expert sources
